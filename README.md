# 🏠 UrbanNest – Real Estate Web Application (MERN Stack)

UrbanNest is a full-stack real estate web application where users can register, log in, and create property listings. It allows users to upload images, filter/search for properties, and manage their own listings. The project is built using the **MERN stack** (MongoDB, Express.js, React, Node.js) with **JWT authentication**, **Google OAuth**, and **Firebase Storage** integration for image uploads.

---

## 🚀 Features

- User registration and login with JWT & Google OAuth
- Property listing creation, editing, and deletion
- Secure image uploads using Firebase Storage
- Advanced property search and filtering
- Protected routes and role-based access control
- Responsive design with Tailwind CSS

## 🛠️ Tech Stack

**Frontend:**
- React.js
- React Router DOM
- Tailwind CSS
- Redux Toolkit

**Run front** : cd client then npm run dev

**Backend:**
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT (jsonwebtoken)
- bcryptjs
- Cookie-parser

  **Run backend/server** : cd api then npm run dev

**Other Tools:**
- Firebase Storage
- Vercel (deployment)
- Git & GitHub
